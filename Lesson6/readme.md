# Lesson 6 — Asynchronous JavaScript & Error Handling

##  Overview
This lesson covers:
- asynchronous JavaScript (callbacks, promises, async/await)
- error handling (try/catch)
- basic debugging

##  Files
- `async.js` — examples of async/await and promises
- `error-handling.js` — try/catch usage

##  Tasks
- Create async function using `async/await`
- Handle errors with `try/catch`
- Simulate API request (use Promise)
- Log and debug errors

##  Goal
Learn how to work with asynchronous code and handle errors correctly.
